Umineko When They Cry

This browser cannot keep a game on the device. Use a recent Safari, Chrome, Edge or Firefox.

On iPhone and iPad, first add this page to the Home Screen: tap Share, then Add to Home Screen. Then open Umineko from the Home Screen and import the game there. A game imported in Safari stays in Safari, and Safari deletes it after a few weeks without a visit.

Add a game

You need the game files from your own copy of the game (Steam). They are copied into this browser, on this device only: nothing is sent anywhere.

Where are the game files?
  1. In Steam, right-click the game, then Manage → Browse local files. The folder that opens is the game folder (it holds arc.nsa and 0.utf).
  2. On a computer: Choose the game folder above and pick that folder.
  3. For a phone or tablet, make a zip of that folder on the computer: right-click it, then Compress (Mac) or Send to → Compressed (zipped) folder (Windows). Put the zip on iCloud Drive or Google Drive, or send it to the phone with AirDrop, then Choose a zip above.
  4. Once the game is imported, the zip can be deleted to get the room back.

The Question Arcs need about 2.7 GB free, the Answer Arcs about 4 GB, plus room for the zip while importing.
